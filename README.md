# PixelCraft Digital Website

A responsive starter website project for PixelCraft Digital.

## Files
- `index.html` — page content and sections
- `style.css` — layout, responsive styling and animations
- `script.js` — mobile menu, reveal effects, contact-form email draft
- `assets/logo.svg` — logo artwork

## Run locally
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use Live Server.

## Before using with customers
1. Contact email is configured in `script.js`.
2. WhatsApp number is configured in `script.js` in international format.
3. Update service prices and scope to match what you can deliver.
4. Replace concept portfolio pieces with actual work; clearly label practice projects.
5. Use only photos, fonts and assets you have rights to use.
6. Ask a trusted adult for support with unfamiliar customer contacts and payments.

The contact form uses a `mailto:` link; it does not store form data or send directly from a server.
The site is a static project. Hosting, domain, payment handling and backend features are not included.
